# 动态

[English](../en/feed.md) · **中文**

首页就是一个实时动态，Awesome 上发生的一切尽在其中。

| 标签 | 显示内容 |
|---|---|
| **全部（All）** | 下面所有内容，最新的在前 |
| **新币（Launches）** | 新币和毕业，$牛逼 置顶 |
| **广场（Posts）** | 社区帖子 |
| **推特（X）** | 带动 BNB Chain 行情的账号发的推特：BNB Chain、Binance、PancakeSwap、four.meme、flap.sh、牛逼 社区等 |
| **大单（Trades）** | Awesome 币的大额买入，以及 $牛逼 的买卖 |

- 推特里提到的 `$TICKER` 或 Awesome 已知的合约地址，会直接链接到对应的币。
- 其他语言的帖子可以原地翻译（English ↔ 中文）。

## 发帖

连接钱包并签名一条消息（免费，不发交易）即可发帖。帖子为纯文本，最多 280 个字符，可以标记一个币。链接仅限 x.com、t.me、niúbī.xyz 和
bscscan.com。限制：每个钱包每 30 秒最多发一条，每天最多 50 条。
