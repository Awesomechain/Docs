# 发射类型

[English](../en/launch-types.md) · **中文**

每个币在发射时都要选一个 **发射类型**。它决定每笔交易手续费中的 **创建者分成**（60%）流向哪里。发射类型在发射时写入链上，**永远无法更改**，所以持有人始终清楚手续费的用途。

## Dev Bag（开发者钱包）

创建者分成 **归创建者所有**，随时可在 **我的（Profile）** 页面领取。经典、简单。

- 任何人都可以触发发放，但钱只会打给创建者。
- 创建者可以把币转交给另一个钱包（先发起，再接受），手续费随之转移。

## Flywheel（飞轮回购）

创建者分成 **在币自己的池子里回购本币并销毁**。每一笔交易都在缩减供应量。

- 回购由 Awesome 的 keeper（执行者）定期执行，或由创建者执行。
- 其他人都无法触发，所以没人能踩着回购的时间点抢跑。
- 被销毁的代币会被彻底销毁（`burn()`）：总供应量永久减少。

## Bull Run（牛市燃烧）

创建者分成 **买入 $牛逼 并销毁**。每一笔交易都在拉升 $牛逼。

- 仅限原生币交易对的币。
- 在 BNB Chain 上全程链上完成：手续费通过白名单内的 PancakeSwap 池子买入 $牛逼，并发送到
  `0x000000000000000000000000000000000000dEaD`。合约会校验 $牛逼 确实到账。
- 在其他链上，Bull Run 的份额会被转到 BNB Chain，用于买入并销毁 $牛逼。
- 网站会显示 Bull Run 币累计销毁了多少 $牛逼。

## Holder Drip（持有人分红）

创建者分成 **按持仓比例发给该币的持有人**。

- 每个轮次都会给持有人拍一次快照（排除池子、合约和销毁地址），并以 merkle 树的形式发布。
- 持有人在 **我的（Profile）** 页面领取自己的份额（任何人都可以代为提交某个持有人的领取，钱始终打给该持有人）。
- 90 天内未领取的金额会退回奖池，计入之后的轮次。

## Squad（团队分成）

创建者分成 **按发射时设定的固定比例分给 2 到 5 个钱包**（例如 50 / 30 / 20）。

- 每位成员随时领取自己的份额；一位成员领取不会影响其他人的份额。
- 成员和比例在发射后都无法更改。

## 对比

| | 谁受益 | 适合 |
|---|---|---|
| Dev Bag | 创建者 | 自己建设、推广项目的创建者 |
| Flywheel | 所有持有人（供应量减少） | 社区币、通缩 |
| Bull Run | $牛逼 持有人 | 蹭牛逼叙事的币 |
| Holder Drip | 持有人，以原生币或计价代币支付 | “持币生息”型的币 |
| Squad | 一个团队 | 团队、联名合作、KOL 发射 |

无论哪种类型，每笔手续费的其余部分都按同样的方式分配：详见[手续费](fees.md)。
