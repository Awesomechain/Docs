# 常见问题

[English](../en/faq.md) · **中文**

**牛逼是什么意思？**
中文里的“awesome”（niúbī）。牛就是公牛。

**发射要花多少钱？**
只要 gas，如果做了首笔买入，再加上首笔买入的金额。

**创建者能撤走流动性吗？**
不能。在 EVM 链上，全部供应量永久锁在池子里，也没有任何能撤出流动性的函数。

**毕业时会发生什么？**
币继续在同一个池子里交易，手续费不变。什么都不用迁移。

**为什么我在刚发射时买入，成本这么高？**
前 10 秒是防狙击窗口：手续费 50%，单笔最多买入总量的 1%。

**手续费去哪儿了？**
60% 给该币的发射类型，10% 给 Awesome 平台，10% 给 牛逼 质押，20% 用于回购并销毁 $牛逼。详见[手续费](fees.md)。

**之后能改我的币的发射类型吗？**
不能。它在发射时就固定了，所以持有人可以放心。

**怎么领取我的创建者手续费？**
我的（Profile）→ 领取（Claim）。详见[领取](claiming.md)。

**我发错链了，能把币挪过去吗？**
不能，币只存在于它发射时所在的链上。

**有 API 吗？**
有，还有 SDK、已验证的合约和智能体技能。详见[开发者](developers.md)。
