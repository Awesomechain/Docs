# 手续费

[English](../en/fees.md) · **中文**

## 一笔交易要花多少

| | 手续费 |
|---|---|
| BNB Chain | 每笔买入和卖出的 **1%** |
| Uniswap v4 链 | **1%**，或创建者在发射时选定的费率（0.25% - 5%） |
| Solana | 平台自身的手续费（Pump.fun；Raydium LaunchLab 档位 1% - 5%） |
| 发射后的前 10 秒 | 50%（[防狙击窗口](trading.md#防狙击窗口)） |

手续费从交易的原生币（或计价代币）一侧收取，在池子内部、同一笔交易里完成。发射本身只花 gas。

## 每笔手续费流向哪里

| 比例 | 去向 |
|---|---|
| **60%** | 该币的[发射类型](launch-types.md)：创建者、回购并销毁本币、销毁 $牛逼、持有人或一个团队 |
| **10%** | Awesome 平台 |
| **10%** | 牛逼 质押 |
| **20%** | 回购并销毁 **$牛逼** |

这 20% 的回购销毁来自 **每一条链**：在 Base、Solana 或任何其他链上赚到的手续费，同样用来买入并销毁 $牛逼。

与可销毁配对代币（four.meme、flap.sh、锁仓 LP 或另一个 Awesome 币）配对的币，每笔交易还会销毁其配对代币。详见[配对](pairings.md)。

## 在哪里查看

- 每个币的页面都会显示其交易支付了多少手续费，以及发射类型拿这些手续费做了什么。
- $牛逼 页面会显示 $牛逼 的累计销毁量。
- 每一笔手续费都在链上：hook 在每笔交易时都会发出 `SwapFee` 事件，fee vault 合约会记录每一笔发放。详见
  [Contracts](https://github.com/Awesomechain/Contracts)。
