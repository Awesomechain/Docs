# 配对（BNB Chain）

[English](../en/pairings.md) · **中文**

币通常与 BNB 配对。在 BNB Chain 上，它也可以改为与一个 **配对代币** 配对，这样新币的每一笔交易也会为那个代币的社区出一份力。

| 配对代币 | 是否销毁 |
|---|---|
| **four.meme** 代币 | 是 |
| **flap.sh** 代币 | 是 |
| **锁仓 LP** 代币（PancakeSwap V2 流动性大部分已销毁） | 是 |
| **另一个 Awesome 币**（最多嵌套 3 层） | 是 |
| **股票代币**（bStocks、Ondo） | 否 |

## $50K 门槛

一个代币只有在 **市值不低于 $50,000** 时才能被新币配对，每次发射都会检查：

- 价格取最近若干次读数的中位数（至少 5 次，每次间隔一分钟），每次读数都被限制在中位数的 10% 以内，所以单个区块的拉盘无法造假；
- 新登记的代币要等 30 分钟才能迎来第一次发射；
- 配对页面会显示每个代币的市值、状态，以及基于它发射的币。

## 销毁

与可销毁配对代币配对的币，每笔手续费的一部分会在同一笔交易里 **销毁该配对代币**。如果配对代币本身就是基于另一个代币发射的 Awesome
币，销毁会沿着链条逐层向上，每一层都会销毁（例如两层时按 70% / 30%，三层时按 60% / 20% / 20%）。

## 用 BNB 买

你不需要持有配对代币。直接用 BNB 买，路由会在同一笔交易里先买入配对代币、再买入这个币（卖出则反向进行）。股票代币可能并非在所有地区都可用。
