# 快速上手

[English](../en/getting-started.md) · **中文**

## 1. 打开网站

访问 **[niúbī.xyz](https://xn--nib-9na0w.xyz)**（在某些浏览器和钱包里，地址会显示为 `xn--nib-9na0w.xyz`：是同一个网站）。页头的语言切换可以在 English 和中文之间切换。

## 2. 连接钱包

点击 **连接钱包（Connect）**。

- **EVM 链**（BNB Chain、Base、Arbitrum、HyperEVM、Monad、X Layer、Elysium、Robinhood Chain、Arc）：任何注入式钱包（MetaMask、OKX
  Wallet、Binance Wallet、Rabby、Trust…）或 WalletConnect。
- **Solana**：任何支持 Wallet Standard 的 Solana 钱包（Phantom、Solflare、Backpack、OKX…）。

你只需要准备该链原生币作为 gas：BNB Chain 用 BNB；Base、Arbitrum 和 Robinhood Chain 用 ETH；HyperEVM 和 Elysium 用 HYPE；Monad 用
MON；X Layer 用 OKB；Arc 用 USDC；Solana 用 SOL。

## 3. 找币

- **首页（动态）** 实时展示新发射、毕业和大单买入。详见[动态](feed.md)。
- **代币（Coins）** 列出每条链上的所有币，可按最新、热门、市值、即将毕业或销毁最多排序。链筛选器决定你能看到哪些链。
- **搜索**（顶部栏）可按名称、代号或合约地址找币。

币的页面会显示 K 线、毕业进度、成交记录、持有人、该币的发射类型，以及手续费都去了哪里。

## 4. 买入和卖出

在币的页面上，在交易框里输入数量，然后点 **买入（Buy）** 或 **卖出（Sell）**。钱包会弹出交易让你确认。滑点在交易框里设置（默认 1%）。价格如何变动请看[交易](trading.md)。

## 5. 发射你自己的币

点击页头的 **发币（Launch）**。大约一分钟搞定：详见[发射一个币](launching.md)。

## 注意安全

- 唯一官方网站是 **niúbī.xyz**（`xn--nib-9na0w.xyz`）。连接钱包前先核对地址。
- Awesome 绝不会向你索要助记词或私钥。
- 官方合约地址见[链](chains.md)页面和 [Contracts](https://github.com/Awesomechain/Contracts) 仓库。
- 任何人都可以发射币。一个币出现在 Awesome 上，不代表 Awesome 为它背书。
