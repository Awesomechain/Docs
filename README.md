# Awesome (牛逼) documentation

**English** · [中文](README.zh-CN.md)

Awesome is the **牛逼** launchpad. Launch a coin in one transaction, with its whole supply locked forever in a
bonding-curve pool, pick where its creator fees go, and trade it on **BNB Chain**, **eight more EVM chains** and
**Solana**.
