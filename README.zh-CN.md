# Awesome（牛逼）文档

[English](README.md) · **中文**

Awesome 是 **牛逼** 的发射台。一笔交易就能发射一个币，全部供应量永久锁在联合曲线池子里；手续费的创建者分成去哪儿由你来定；在
**BNB Chain**、**另外八条 EVM 链** 和 **Solana** 上都能交易。

**官网：** [niúbī.xyz](https://xn--nib-9na0w.xyz) · **Telegram：** [t.me/awesomebsc](https://t.me/awesomebsc) ·
**主币：** $牛逼 `0x9665f094d862f4d5c221843e019b463d3c607777`（BNB Chain）
